# Quiz Basic

Projeto acadêmico de quiz desenvolvido no Construct 2 durante atividades no ENIAC, com orientação do professor Marcos Carfora. O trabalho também explora a criação de recursos gráficos com Inkscape.

## Conteúdo do repositório

- `Quiz_university_Eniac.capx`: arquivo-fonte do projeto no Construct 2.
- `assets_quiz/`: imagens de perguntas, alternativas, estados de resposta e layouts em PNG e SVG.

## Como abrir

1. Instale uma versão compatível do Construct 2.
2. Abra `Quiz_university_Eniac.capx` no editor.
3. Use a opção de pré-visualização do Construct 2 para executar o projeto.

O repositório contém o projeto editável; não inclui uma exportação HTML pronta para abrir diretamente no navegador.

## Tecnologias e aprendizados

- **Construct 2:** construção de um quiz em ambiente visual.
- **Inkscape:** preparação de elementos gráficos e layouts.
- **Organização de assets:** separação de perguntas, alternativas e feedback visual.
